01 · Industrial desktop software In testing · not yet in production

Nova Control

One Windows program that runs a ready-mix concrete plant’s whole day, from the customer’s order and truckloads to batch records, invoices and reports. It also talks in real time to the plant’s existing PLCs (the industrial computers that run the machines).

Built to survive failures: if the connection drops or the PC restarts mid-order, nothing is produced twice and nothing is lost.

How it works and how it was tested

What it does

A dispatcher screen with today’s orders, each mixer and the stock in every bin. Truckloads are split into batches with exact material weights, adjusted for the moisture in the sand and gravel. A live operator screen shows weights as the PLC doses them. The program also covers recipes to EN 206, delivery notes, invoices in euro, CSV/Excel reports and automatic daily backups. The interface is in Bulgarian.

The hard part

It must work with the PLCs and control programs already installed at the plants, unchanged. The industrial communication protocols (Omron FINS over network and serial links) were implemented from scratch. The memory layout was traced from the plant’s own PLC program. Before every order it checks the hopper numbers in the PLC, and a mismatch stops the queue instead of dosing from the wrong bin.

Testing and status

524 automated checks run against a built-in PLC simulator over real network connections. They cover 3,150 order layouts, 25% packet loss, slow links and restarts mid-exchange. After several audit rounds, every confirmed finding got a fix and a regression test, growing the suite from 81 to 524 checks. The software is feature-complete. The next step is a bench test with a real PLC, before any plant.

02 · Chrome & Edge extension Live on the Chrome Web Store

Fake Discount Bulgaria

Shows whether a “discount” in a Bulgarian online store is real by comparing it with the prices you have actually seen, as a chart right on the product page.

Chrome Web Store ↗ Source code ↗
How it works and how it was tested

What it does

When you open a product in a supported store, the extension records that day’s price. A panel then shows today’s, lowest, average and highest price, and a chart with the store’s claimed “was” price. A popup lists everything you follow, with search, store filters and mini price charts. You can export your history and switch between light and dark mode.

Reading prices reliably

Each of the 20 stores has its own reader. It finds the real price in the page data, follows in-page navigation and spots sold-out products. It also ignores “reference” prices, like a manufacturer’s suggested price, that were never real previous prices. The panel sits in a Shadow DOM, so store styles cannot break it.

Privacy and testing

No server, no account, no tracking: since version 3.19, nothing leaves the browser. The 86 automated tests use 54 real product pages saved from the supported stores, recaptured in October 2026. Verdicts are a guide, not proof, because they only use prices your browser has seen.

How it works and how it was tested

Live personalisation

Invitations, gift boxes, tags, place cards, thank-you cards and welcome boards redraw as the customer types: watercolour artwork with editable lettering on top. A “full set” view arranges the chosen items in one scene. The guest count fills in quantities, and the event date is checked against the workshop’s lead time, including Bulgarian holidays.

Request, not checkout

Customers send a non-binding request and the workshop confirms by phone, so there is no online payment. Requests can be shared as a link or as a text summary for Viber. Safeguards prevent double sending, conflicting edits across browser tabs and lost drafts. Volume discounts of 5–15% apply automatically.

Behind the scenes

A private owner area and design storage run on serverless functions, a Postgres database and secure login. Saved designs are deleted automatically after 90 days. The site has no analytics or ad scripts. Every build is scanned so private files and secrets cannot be published, and releases go alpha → beta → production.

How it works and how it was tested

What I built

An industrial “technical drawing” design with eight service pages and FAQs. A project gallery has category filters and a full-screen viewer that works with swipe and arrow keys. The workshop’s machines are shown as line drawings with data from their nameplates. The site also has a quote form and 16 EU project documents.

Speed, search and privacy

Photos come in modern formats at three sizes, and fonts are self-hosted. The main content loaded in under 0.7 s in local tests. Structured data and language links help search engines, and old WordPress links redirect to the new pages. The site has no analytics or tracking cookies and uses a strict security policy.

Automated browser testing

A Playwright suite opens all 32 pages at seven screen widths, from 320 to 2560 pixels, looking for layout overflow, broken images and console errors. It also tests navigation, the gallery, language switching, the contact form and a no-JavaScript pass.
