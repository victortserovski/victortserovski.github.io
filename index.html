Nova Control: features and testing

Dispatch and production records

Orders, mixer queues and stock levels sit in one dispatcher view. The application splits truckloads into batches, calculates target material weights with moisture adjustments, and records the PLC’s reported quantities. It also handles recipe records, delivery notes, invoices, reports and daily backups. The interface is in Bulgarian.

PLC integration

The communication layer implements Omron FINS and Host Link protocols for the plant’s existing PLC programs. The address map was traced from the plant’s ladder program. Before sending an order, the application checks the hopper configuration and pauses the queue if it finds a mismatch.

Testing and status

A PLC simulator supports 524 automated checks over local UDP and TCP connections. Tests cover 3,150 combinations of order data, 25% packet loss, slow responses and interrupted exchanges. The planned features are implemented; bench testing with a real PLC is the next step before plant use.

Fake Discount Bulgaria: features and testing

Price history while you browse

Visiting an enabled product page records one price snapshot per day. The panel shows recorded prices and a history chart; the popup lists recorded products with search, store filters and small trend charts. History can be exported and imported, and the interface follows your system’s light or dark theme.

Retailer-specific price readers

Separate readers handle the 20 supported stores, including in-page navigation and unavailable products. They distinguish the current selling price from reference labels such as a manufacturer’s recommended price. Shadow DOM separates the panel’s styling from the retailer’s page styles.

Privacy and testing

Since version 3.19, recorded price history stays in local browser storage. The automated suite includes fixtures from 54 saved retailer pages. Price signals use only observed history and may prompt a closer look at a claimed discount; they do not prove deception.

Малки Подаръчета: features and testing

Live personalisation

Names and event details update on previews of invitations, boxes, tags, place cards, thank-you cards and welcome boards. A set view brings the chosen items together. Guest counts suggest quantities, while event dates are checked against workshop lead times. Previews are illustrative; the workshop confirms the final design before production.

Requests shaped around the business

Customers send a non-binding request for confirmation by phone. They can edit saved sets, share a request link or copy a text summary. Draft saving, coordination across browser tabs and submission guards help protect the request flow. Volume discounts apply to eligible studio products.

Implementation and testing

Next.js pre-renders 79 pages. Local integration tests cover request handling, design storage and retention, with browser checks for previews, editing and shared requests. Saved design specifications expire from the database after 90 days. Build checks scan exported pages and function bundles for private files and secrets. The site uses no analytics or advertising scripts.

SIMA-MA: features and testing

Content and navigation

Eight services have dedicated pages in both languages, presented in an industrial technical-drawing style. Visitors can filter the project gallery, inspect photos in a full-screen viewer and request a quote for a selected service. Illustrations of the workshop machines use information from their nameplates.

Performance, search and privacy

Photos are supplied in AVIF and WebP at three widths, with self-hosted fonts. Language links, structured data and redirects support the bilingual content and preserve old WordPress URLs. The site has no analytics or advertising cookies.

Build and browser checks

Build checks validate generated pages, media, metadata and the security policy; a detected failure stops the build. A separate Playwright suite checks all 32 pages at seven screen widths, from 320 to 2560 pixels, plus navigation, the gallery, language switching, forms and behaviour without JavaScript.
