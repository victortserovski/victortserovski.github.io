## Site maintenance

The Systems design uses plain HTML and CSS, system fonts, responsive WebP portraits, native video controls, and expandable project details. There are no runtime JavaScript dependencies or build steps.

- Edit content in `index.html` and styles in `portfolio.css`.
- Keep published media and the CV in `assets/`.
- Preview locally with `python -m http.server 8000`, then open `http://localhost:8000/`.
- GitHub Pages publishes the `main` branch from the repository root. `.nojekyll` keeps it a static site.

The social preview is [`assets/portfolio-linkedin-2026.png`](assets/portfolio-linkedin-2026.png), a 1738 × 905 image generated with built-in imagegen using Victor’s portrait as a reference. Open Graph and Twitter metadata point to this versioned image. Use [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/) to refresh a cached link preview.
